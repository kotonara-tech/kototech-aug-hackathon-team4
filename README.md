# 開発者およびコーディングエージェント向け

初めて本プロジェクトに入る人は、以下の順序で開発に入ること。

1. docs配下overview.mdを見る
2. 自分が担当する領域のdocs配下の設計書を見る
3. 自分が担当する領域の00-openquestion.mdを確認し、未決事項を確認する
4. 実装作業に入る

# ルール

設計正本は必ず、docs配下にあるものを正本とする。
実装は誤っている場合があるため、現実装は信用しない。

開発開始する場合は以下の動作を踏み、リモートの状況を確認すること

```
git fetch
git pull origin develop
```
