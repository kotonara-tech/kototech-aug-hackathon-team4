# 担当A（Android）↔ 担当B（Web）連携仕様

POC 結合時に「1枚も表示されない」を避けるための取り決めです。
**★印は一致していないと動きません。**

## 1. 保存先フォルダ ★

Android アプリは、ログインしたユーザーのマイドライブ直下に
**`FarmCameraPOC`** という名前のフォルダを作り、その中に保存してください。

```
マイドライブ/
└── FarmCameraPOC/          ★ この名前で一致させる（大文字小文字も一致）
    ├── IMG_20260820_063000.jpg
    └── IMG_20260820_183000.jpg
```

サブフォルダを作った場合、Web 側は**サブフォルダ名を「カメラ設置場所」として表示**し、
絞り込みできるようにします（任意。POC では作らなくて構いません）。

```
マイドライブ/
└── FarmCameraPOC/
    ├── 第1ハウス/          → 画面に「第1ハウス」として絞り込みボタンが出る
    └── 第2ハウス/
```

## 2. ファイル形式 ★

- **JPEG**（`image/jpeg`）で保存してください。
- Web 側は `image/` で始まる MIME タイプ全般を表示できるため、PNG でも表示は可能です。
- ファイル名の規則は問いません（Web 側は名前で日時を判定していません）。

## 3. 撮影日時 ★

Web 側は次の優先順位で撮影日時を決めます。

1. **EXIF の撮影日時**（Drive の `imageMediaMetadata.time`）
2. なければ Drive の `createdTime`（アップロード日時）

**EXIF を残したまま保存してください。** 圃場は電波が弱くアップロードが遅れるため、
EXIF が無いと「朝6時の写真」が「夕方18時」と表示されてしまいます。

EXIF の日時は**タイムゾーン情報を持たない現地時刻**として扱い、Web 側は JST として解釈します。

## 4. OAuth 設定

同じ Google Cloud プロジェクト内に、クライアントを **2つ** 作成します。

| 用途 | クライアントの種類 | 備考 |
|---|---|---|
| Android | Android | パッケージ名と SHA-1 フィンガープリントが必要 |
| Web | ウェブ アプリケーション | リダイレクト URI: `http://localhost:8000/auth/callback` |

### 必要なスコープ

| 担当 | スコープ | 理由 |
|---|---|---|
| Android | `https://www.googleapis.com/auth/drive.file` | 自分が作ったファイルの読み書き |
| Web | `https://www.googleapis.com/auth/drive.readonly` | 閲覧のみ |

> **注意（POC で詰まりやすい点）**
> Android が `drive.file` で保存したファイルは、**同じ Google アカウントでログインすれば**
> Web 側の `drive.readonly` から見えます。
> **Android と Web で同じアカウントを使ってデモしてください。**
> 別アカウントで試すと、正しく実装していても 0 枚になります。

### OAuth 同意画面

- ユーザーの種類: 外部
- 公開ステータスが「テスト」の間は、**デモで使うアカウントをテストユーザーに登録**すること
  （未登録のアカウントはログイン時に弾かれます）

## 5. 担当A から担当B へ共有してほしいもの

- [ ] Google Cloud のプロジェクト ID
- [ ] Web 用 OAuth クライアントの **クライアント ID**
- [ ] Web 用 OAuth クライアントの **クライアントシークレット**
- [ ] デモに使う Google アカウントのメールアドレス（テストユーザー登録の確認用）

担当B はこれらを `.env` に設定します（`.env.example` 参照）。

## 6. 結合時の確認手順

1. Android アプリで 1 枚撮影 → アップロード
2. ブラウザで https://drive.google.com を開き、`FarmCameraPOC` に画像があることを目視確認
3. Web アプリ（http://localhost:8000）に**同じアカウント**でログイン
4. 「最新の写真」に該当画像が出れば結合成功

3 でログインできるのに 4 で 0 枚の場合、疑うのはこの順です:
フォルダ名の不一致 → アカウント違い → ファイルがゴミ箱にある
