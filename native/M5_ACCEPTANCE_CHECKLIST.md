# M5 実機・Web 合同受入チェックリスト

M5 は実機、デモ用 Google アカウント、Web SPA を同時に使う受入工程です。自動テストでは代替しません。

## 事前準備

- [ ] Android 実機へ `android/app/build/outputs/apk/debug/app-debug.apk` をインストールする
- [ ] 実機のカメラ権限と通知権限を許可する
- [ ] デモ端末をバッテリー最適化の対象外にする
- [ ] Android と Web の OAuth クライアントが同一 GCP プロジェクトにあることを確認する
- [ ] Web の `.env.local` に Web OAuth クライアント ID を設定する

## Native

- [ ] アプリを開き、開始を押して Google サインインと `drive.appdata` 認可を完了する
- [ ] 常駐通知が表示され、画面の開始ボタンが無効・停止ボタンが有効になる
- [ ] 5 分間隔で撮影枚数と送信枚数が増える
- [ ] 最終送信時刻が更新され、直近エラーが「なし」のままである
- [ ] アプリをバックグラウンドにしても、次の撮影・送信が継続する
- [ ] 停止を押すと通知が消え、開始ボタンが有効になる

## Web 合同確認

- [ ] Web SPA を同一 Google アカウントでログインする
- [ ] AppData の一覧に Native で送信した JPEG が表示される
- [ ] 最新画像を開ける
- [ ] 表示される撮影時刻が `imageMediaMetadata.time` の値と一致する
- [ ] Native の次回送信後、Web のポーリングで新しい画像が表示される
